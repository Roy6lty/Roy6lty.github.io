Set up the lab
before the network grows.

Complete this short setup session once. It gets the source code, Docker host, first smoke test, and required mental models in place before Chapter 01.

TIME / 20 - 30 MINUTES
01 / SOURCE

Clone the course repository.

Use the maintained repository for the Compose stages, scripts, chapter files, diagrams, and troubleshooting checks. Clone it into docker-subnet so the Compose project name matches the network and container examples used in this course.

HOSTRUN ON YOUR MACHINE
git clone https://github.com/Roy6lty/Network-series.git docker-subnet
cd docker-subnet
Open the Network-series repository ↗
02 / ENGINE

Install Docker with Compose v2.

Choose the Docker installation for your operating system. The course needs Compose v2 and permission to create networks, routes, and containers.

Open the Docker installation guide ↗
HOSTVERIFY INSTALLATION
docker --version
docker compose version
03 / VERIFY

Run the first smoke test.

From the cloned repository root, build and stop Chapter 01. This checks Docker access, Compose v2, image builds, and the course runner before networking begins.

HOSTRUN FROM REPOSITORY ROOT
bash scripts/compose-stage.sh 01 up -d --build
bash scripts/compose-stage.sh 01 ps
bash scripts/compose-stage.sh 01 down
04 / KNOW BEFORE YOU START

Bring the foundation.

You do not need advanced networking, but you should be comfortable with:

  • Shell navigation, pipes, environment variables, and command output.
  • Images, containers, volumes, Compose services, and logs.
  • IPv4 CIDR notation, interfaces, routes, gateways, and next hops.
  • Processes, permissions, namespaces, and basic failure diagnosis.
READY CHECKUse a disposable Linux-capable Docker environment.

The lab intentionally uses NET_ADMIN, NET_RAW, packet capture, routing, firewall rules, fixed CIDRs, and local PostgreSQL volumes. Check for overlapping Docker networks before you begin.
