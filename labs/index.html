Engineering labs / run locally

Build it.
Break it.
Understand it.

These labs turn infrastructure concepts into systems you can inspect. Each one is designed around building a small environment, observing what the operating system or runtime actually does, breaking one dependency, and reasoning from evidence.

LAB METHOD / AO
BUILD→RUN→OBSERVE→BREAK→FIX→REVIEW

Commands run on your own machine. The site provides the learning path, diagrams, explanations, checkpoints, and recovery guidance.

Design principle

The lab is not the command list.
It is the reasoning around it.

Each course should preserve the real questions, failed assumptions, diagnostic evidence, fixes, and mental models that make the system understandable to another engineer.
